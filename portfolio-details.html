Veterinaria Patitas Felices

Sistema web full stack orientado a la gestión de clínicas veterinarias. Permite administrar pacientes, dueños e historiales clínicos en una plataforma centralizada con autenticación segura y control de roles.

Desarrollé una arquitectura completa cliente-servidor, implementando autenticación con JWT, encriptación de contraseñas y una API REST para la gestión eficiente de datos. El sistema está desplegado en la nube utilizando servicios modernos para frontend, backend y base de datos.

Funcionalidades principales

Autenticación y autorización

  • Login con JWT
  • Encriptación de contraseñas con bcrypt
  • Manejo de roles de usuario

Gestión de pacientes

  • CRUD de mascotas
  • Asociación con sus respectivos dueños

Historia clínica

  • Registro y edición de historial médico
  • Relación entre mascota, dueño y atención clínica

Gestión de dueños

  • Alta, baja y modificación de clientes

Tecnologías utilizadas

Frontend

  • HTML5, CSS3, JavaScript
  • Bootstrap 5
  • Vite

Backend

  • Node.js + TypeScript
  • Express
  • MySQL (mysql2)
  • JWT + bcrypt

Base de datos

  • MySQL
  • Docker + phpMyAdmin (entorno local)
  • Railway (producción)

Deploy

  • Frontend: Vercel
  • Backend: Render
  • Base de datos: Railway
